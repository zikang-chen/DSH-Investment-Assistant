# Institutional Finance UI 升级：审计与阶段验收

## 本轮范围与边界

本轮优先 Phase 0、Phase 1 及 Phase 2 首页/投资判断。不是整个产品的视觉最终验收。

- 基线：提交 `86e0c98`；开始时工作区干净。
- 分支：`feat/institutional-finance-ui`。不强推、不改远端、不迁移/覆盖任何私人数据。
- 保持 Cordis 包身份、Tools/Skills/MCP、面板导航、SSE、API 参数和金融计算不变。
- 本轮修改限前端、展示测试、设计文档与 CI。资本/复利/投资判断/政策后端计算和原数据文件无 diff。
- 没有更换字体包、引入商业素材、安装新的运行依赖或启动替代 Web 应用。

- `src/client/design-system/`：轻/深主题、跟随宿主、三种涨跌模式、独立 status/chart Token；本地偏好容错与跨 Portal 同步；可复用 Button/PageHeader/StatusBadge/EmptyState/MetricCard；显示格式化。

- 原有 S/V 通过兼容映射获得统一背景、正文、边框、按钮。修复会将 `var(--color)` 拼成无效 `var(--color)1f` 的代码。

## Phase 2：首页与投资判断

### 首页

- 标题「今日投资工作台」；紧凑问题入口；四卡与政策/待办研究区。
- 区分请求未返回、读取失败、暂无记录；不把缺失误写0。
- 显示“本机读取时间，不代表报价时间”；政策保留发布日期/来源；净投入明示不是收益。
- 原个人首页 embedded 模式去 hero、重复统计；保留档案、规划风险修复、周复盘、待确认人工审批等入口。
- 所点政策标题传递具体 id 聚焦原文，而非仅跳一个列表。

### 投资判断

- 快速/深度模式、单一“开始分析”主按钮、Ctrl/⌘+Enter、示例只填入不擅自发送。
- 个人组合授权默认关闭，开启时仅声明本次研究权限，不猜用户风险预算。
- 正确处理列表、详情、失败、过期响应与 SSE 重载；详情独立展示真实数据时效对象。
- 当前判断/支持证据/反证/行动条件/资料时点/待补证据/复盘分区。买入不渲染成“绿色盈利承诺”。
- 保留原有生成对立观点、复盘、历史验证、政策跳转等真实操作；新增证据缺口按钮通过已有会话投递，不伪造完成状态。
- 详情动作附近显示实际投递反馈。学习通过按需原生 dialog 提供三级解释、Escape与焦点返回。
- 已选研究 id 放在外层，跳政策再回投资判断仍能重新打开原记录；暂未保存精确滚动位置。

## Phase 3–4：证券检索、持仓、资本与数据源

- **名称/代码检索**：新增统一的 `SecuritySearch`，输入中文名称片段（如「中国」）或代码后经真实 `/search` 数据源返回候选，显示名称、代码、市场与资产类型；键盘 ↑↓/Enter/Esc、输入法合成期保护、300ms 防抖、请求序号防旧响应串入、旧选中随输入失效。**不会把第一个模糊匹配当成目标，也不按 6 位代码猜基金。**
- **证券详情 → K线 → Agent**：搜索结果、自选行情、基金排行、持仓行、录入选中项均通过统一的 `SecurityLink` 打开「证券资料与综合研究」：展示档案各维度的真实数据行、来源、数据时点、缺失与截断说明；再一键进入完整 K 线工作区或投递综合分析。
- **Agent 综合分析**：分析提示要求覆盖公司年报/季报、财务与估值、资金流、公告新闻、国内外政策与全球市场；基金则覆盖净值、经理、重仓、回撤、费率与穿透企业财务。支持与反对证据、失效条件、复核日期；默认不读取个人持仓，**只有本次显式勾选授权**才注入持仓成本与既往判断（`/analysis` 默认 `portfolioAuthorized=false`）。勾选只对当前标的的这一次分析生效：切换证券会重建详情状态并清除勾选。
- **档案工具实际数据**：`stock_dossier` / `fund_dossier` 此前只返回状态与条数，现返回**真实上游字段的有界预览**（数组 6 项、对象 30 字段、文本 1200 字符、深度 5、每节 6000 字符/总计 24000 字符、渲染上限 64000 字符），并给出截断路径、遗漏原因、`rows` 与返回条数的区别及补查建议；缺失/错误状态保持原样，不构造 0 或空「已核验」。
- **历史 K 线身份隔离**：`HistoryStore.read/manifest` 支持显式 `kind`（a/hk/us/fund），同代码多身份时拒绝按更新时间猜；`get_history` 透传 `kind`；服务端 `/history`、`/history/manifest` 与 K 线、个股解读、证券详情都传 `kind`。K 线工作区与证券详情用请求序号防止旧响应覆盖新标的，并在加载新代码时清空旧图、区分「无历史」与「读取失败」；基金与股票同码（如 000001）不再互相串线。个股解读弹层以 `type+code` 作为 key，切换标的会重建状态，避免沿用上一个标的的授权。
- **持仓录入**：具名「证券代码/名称、资产类型、数量（股/份）、平均成本（报价币种）」；名称必须经真实候选选择；空白不等于 0；只调用既有 `upsertHolding` 预览，明确「未写入，需到个人首页人工确认」；录入草稿由面板持有，去档案/分析返回后可续填。
- **资本与财富联动**：资本页分开展示父级持仓快照（分币种成本/市值/未实现盈亏、缺行情）与交易账本，**不把两个口径自动相加**，贵金属/无单位或无价格的资产明确列出为未计价。财富规划本金可跟随当前持仓（按币种只用完整现值，不用成本补缺、不跨币种合计）或手动输入；持仓变化只更新只读本金并把旧结果标为待更新，不自动计算/保存。
- **数据源页**：能力默认折叠为摘要行，展开查看来源、端点、健康（unknown 为中性）与启用选择；显式保存才 POST 完整策略；有未保存草稿时刷新/SSE 不覆盖，切页前显式确认。
- **对话驱动研究文档**：`skills/investment-advisor` 与 `docs/conversational-research.md` 说明按问题路由官方来源（公司 IR/交易所、央行、统计机构、IMF/世行/OECD 等）、PDF 通过页渲染逐页核对后引用、白皮书经 `policy_import` 的真实限制、缺失证据恢复与资料/观点双落库。
