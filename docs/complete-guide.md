# DSH 投资助手：完整使用与维护手册

更新日期：2026-11-17。本手册记录当前工作区能力与限制，不把代码存在、离线测试通过、页面可访问等同生产环境全部可用。

## 一、定位与架构

本项目仍为DeepSeek Harness插件，不是独立金融App。工具负责取数与确定性计算，Skill指导研究，金融面板负责交互与展示。持仓、账本、研究资料、政策原文、证据请求和投资判断保存在本机配置目录。

不执行真实交易，不保证收益；无来源/时点/口径的数据不能用模型猜测补齐。

## 二、安装与更新

1. 使用项目要求的Node版本安装依赖，执行`npm run build`。
2. 通过当前DSH版本支持的插件安装入口注册本项目；主入口见[README](<../README.md>)。不要启动另一个开发服务器冒充已运行的桌面页面。
3. Python桥可选，需可用Python与akshare；可通过`DSH_PYTHON_BIN`选择解释器。AKTools MCP可选，不是所有行情工具的强制依赖。
4. WeStock Windows安装应探测westock.exe；没有该源时仅有已实现HTTP备用的能力可回退，不能保证全部能力降级成功。
5. 代码更新后重新构建并重载插件/宿主服务端。浏览器刷新仅能保证重新加载页面资源，不能保证服务端模块已经更新。

不要将真实API Key、账户凭证、持仓、商业数据或未经许可的数据原文提交至公开仓库。

## 页面导航与内容分工

总览只放工作台和证据待办；投资判断下含研究判断、档案与复盘；市场研究包含基金研究和机构追踪；我的资本下含持仓、账户收益、规划目标及学习。成长评分不再放总览，规划建议在「规划与目标」折叠展示。完整导航及返回规则见[页面跳转说明](<product-navigation.md>)。

## 三、日常研究工作流

1. 明确标的/市场/期限/问题；名称候选选定后保留code、市场及secid身份，不靠代码长度猜所有证券。
2. 查询已有资料和数据集，确认来源、统计期、发布日期、抓取时间、单位及复权。
3. 抓取行情、财务、公告、资金、相关政策；免费源不可用时保留缺失与真实错误。
4. 用确定性工具计算指标，检查相同指标的不同来源/口径是否冲突。
5. 输出事实、条件推断、支持证据、反对证据、失效条件及下次复核日；证据不足时不给虚构点位。
6. 使用资料库/结构化投资判断保存可复盘记录；关键缺口通过Evidence Inbox请求补证。

默认不读取个人资产。需要组合上下文时逐请求授权，不能把上次勾选视为永久许可。

## 四、行情、K线与事件

完整细节见[K线手册](<history-kline.md>)。

- 本地A/H/美股历史和全球secid K线为不同取数路径，不要将一处覆盖范围套用到全部市场。
- 本地A股从1990年起请求；港美股窗口4000自然日并受分页/Provider限制。全球K线当前最多500根。
- 「全部」全览已取得的bars，不代表全市场上市历史已核验。
- 历史请求hfq的适配器必须明确支持该口径；unknown不能伪装成hfq。后复权价格不是成交现价。
- 同口径局部数据只合并；增量口径冲突保留旧数据并报错。完整迁移需覆盖旧范围、无已报告分页错误/截断。
- 可见本地页面90秒检查刷新，当日未收盘bar也可更新。缓存TTL、源站延迟和休市仍影响时效，不是逐笔实时。
- 工作日间隔只提示疑似问题，不是确定缺失交易日；不补虚构零值bar。
- 事件日期区分财报报告期与公告可得日，避免回测前视偏差。

## 五、全球市场与中国免费数据

[全球数据来源](<global-data-sources.md>)、[数据审计](<data-source-audit.md>)、[中国免费数据集](<free-cn-datasets.md>)和[注册表设计](<provider-dataset-registry.md>)提供来源细节。

`list_cn_datasets`先列数据集与可用性，`get_cn_dataset`按实际参数请求。返回数字必须有单位和统计期；NaN/null不得写成0。宏观月度不是盘中数据，社融增量不是存量，累计同比不是当月同比，外币不可直接相加。

BaoStock安装成功不代表数据端口可用；此前本机10030端口受阻，不能标已启用。Tushare未验证账户权限时不能声称免费财务/新闻等能力可用；不自动购买积分。

免费访问与再分发授权不同：公开仓库发布适配代码、配置模板与模拟测试数据，不打包授权不明的数据。

## 六、政策、白皮书与统计附件

详见[采集手册](<policy-collection.md>)。

- 最新来源检查用policy_collect；历史列表回溯用policy_collect_official。
- 支持from/to发布日期区间和Next翻页预算，不限11月；未知日期保留unknown。
- 列表和文章详情的公开PDF/Excel/CSV等附件可发现并保存；不等于已结构化成宏观数据库。
- maxDocs包括失败和重复尝试；失败报告ok=false，不用成功绿色掩盖缺失。
- 白皮书属战略指引，不等于财政拨款、订单或公司盈利改善。
- 遵守允许清单、robots、节流；不执行任意JS，不绕验证码/登录。具体文章URL/人工导入是合法补充路径。
- 「检查最新更新」是一次动作；不自动替用户创建新定时任务。

## 七、投资判断、资料与证据

研究记录兼容部分旧字段并为历史证据类型显示中文；兼容显示不意味着旧结论被重新核验。

资料库保存来源、时间、原文引用与观点历史；复盘追加，不覆写原判断。Evidence Inbox记录缺口、接受材料、校验与恢复上下文，用户提交不能自动升级为官方事实。

## 八、数据源管理与故障排查

| 现象 | 检查/处理 |
|---|---|
| 更新代码后行为不变 | 确认build完成、插件实际安装路径、服务端已重载；不是只刷新网页 |
| K线只有少量bars | 查看Provider和起止日期，完整同步；不要把全览按钮当自动补全部历史 |
| 复权冲突 | 保留原缓存，完整同步迁移，不能用几天局部响应替换多年历史 |
| 今日价格仍慢 | 检查抓取时间、Provider缓存/交易所时区；当日日期不是实时证明 |
| 政策没有更早月份 | 提供有效官方历史列表URL与日期/翻页预算，RSS本身可能只含近期 |
| 附件保存但没数字 | 查看解析状态；Excel合并表格/PDF需校验，不填0 |
| Python不可用 | 配置DSH_PYTHON_BIN及依赖，保留真实错误，不随意重装整个宿主 |
| PowerShell乱码/引号错误 | 用文件工具编辑UTF-8；复杂参数写脚本；不要用Set-Content重写源码 |

[Windows专门说明](<windows-powershell-fix.md>)给出可选profile脚本。该脚本未自动安装；编码设置不能解决所有网络/引号/进程问题。

## 十、仍未完成的边界

- 所有国家上市以来历史、全球统一逐笔推送、完整交易所日历尚无保证。
- 动态JS官方栏目需要站点专用合法适配，附件复杂表格结构化仍有限制。
- 后复权、unknown Provider与不同来源的标准化仍须持续核验。
- 本轮没有完成真实浏览器视觉/交互验收，不提供伪造截图。

后续维护应先修复可复现故障、补行为测试，再更新文档；不要为增加接口数量牺牲时效、口径或授权真实性。
