# 官方政策、白皮书与统计表采集指南

更新：2026-11-24。本文对应 `policy_collect_official` 及政策页面的「采集官方页面 / 历史回溯」。

## 1. 能做什么

从允许清单内的公开HTML列表页出发，识别「下一页/下页/Next」，抓取文章正文，并从**列表页和已选择的文章详情页**发现PDF、XLS、XLSX、CSV、DOC、DOCX、ZIP附件。

默认静态抓取。可显式开启 `render_js`，用独立的本机 Chrome/CDP 渲染脚本列表页；不复用用户登录或 cookies，不绕过登录、验证码、付费墙或访问控制。公开可访问也不等于许可允许批量再分发。

## 2. 工具参数

| 参数 | 用途 |
|---|---|
| url | 允许清单内的列表或正文URL |
| maxPages | 列表页尝试数，默认1，最多30 |
| maxDocs | 正文采集尝试预算，默认20，最多50；重复和失败也计数 |
| from / to | 发布日期区间（YYYY-MM-DD），不是统计期 |
| includeAttachments | 工具入口默认true，是否保存公开附件 |
| maxAttachments | 附件数量上限，默认20，最多30 |
| issuer / docType | 发布机关、文档类型，白皮书可用white-paper |
| dry_run | 仅检查列表/输入页并生成有限候选计划；不导入正文、不保存附件。计划不是正文质量验收 |
| max_links | 发现 URL 预算，默认60，最多200；翻页、文章和附件共享，重复URL不重复计数 |
| path_prefix | 跟随链接的绝对路径前缀，默认起始URL所在目录；空结果不自动扩大范围 |
| url_pattern | 文章/翻页/附件URL过滤正则；非法正则直接报错 |
| deadline_sec | 整轮时限，默认90，最多300秒；取数、节流、渲染和附件阶段都受约束 |
| render_js / render_max_pages | 是否用本机Chrome渲染；默认关闭，默认最多3页，硬上限10页 |
| respect_robots | 默认false（用户已授权不检查）；true时恢复检查，不能关闭其他边界 |
| loose_links | 默认true；严格匹配无结果时只放宽链接识别，不放宽主机、目录、正则或预算 |

例如对话中要求：

```text
请用 policy_collect_official 采集这个官方列表页，
url=<已核实的官方列表URL>，from=2024-01-01，to=2025-12-31，
maxPages=10，maxDocs=30，includeAttachments=true。
报告新增、更新、重复、失败和实际覆盖范围，不把未取得的资料当成功。
```

`includeAttachments=true`是“同时下载附件”，**不是只下载附件模式**。

## 3. 面板操作

政策页填官方URL、起始日期和翻页数，点「采集 / 回溯」向当前Agent会话投递任务。`to`可在对话工具参数中指定。

「检查最新更新」触发一次已启用来源的policy_collect；不是自动建立新的后台定时任务。既有自动采集是否启用、频率多少，以当前插件配置为准。源站需要专门分页适配时，通用Next识别不能保证全部历史。

## 4. 日期、预算与结果真实性

- 发布日期优先取URL完整日期或明确发布日期/meta；不拿标题中的“2026年2月社融”充当发布日期。
- 无可靠发布日期时留unknown，不因统计月份而错误排除；这也意味着无法保证未知日期项满足from/to。
- maxDocs按尝试而非成功数计预算；分页直接正文、文章子页、重复、失败共享上限。
- 默认串行节流；错误写入errors，整体ok=false，不再出现全失败却ok=true。
- 发现的文档/附件只在起始 origin、允许清单、路径前缀和正则交集内抓取，包括重定向和渲染最终地址；不自动搜其它栏目。
- robots 默认不检查，`respect_robots=true` 可开启；这不改变访问控制、预算与来源核验要求。

## 5. 保存和解析

文本在保存快照、分配政策id前先过质量闸门：提取后正文少于300字，或 `ICP备 / 网站标识码 / 版权所有 / 主办单位` 合计出现至少2次，返回 `parse_failed`，不入政策库、不镜像资料库。手工文本导入同样检查。旧失败条目不作为有效正文检索或升级证据等级。

合格正文保存原文快照、哈希、段落、版本及来源，再镜像到资料库。PDF未抽取时只能保存 `pdf-pending` 原件，不能声称已读取正文；附件按内容哈希保存，不执行文件内容。

- CSV目前仅计非空文本行，**不是完整CSV字段解析**。
- XLS/XLSX使用本地Python+pandas尝试读取第一张表计行；不成功时行数未知，不能填0。
- PDF/DOC/ZIP被保存不代表正文已解析，也不自动执行或解压内容。
- 附件未自动转成规范化宏观序列，复杂合并表格仍需人工核对或Evidence Inbox。

## 6. 实测和边界

此前本机探测PBOC统计栏目返回200/约89KB，静态HTML中有链接；这仅证明该页面当时可访问，**不等于已对所有子页/附件/历史年份完成端到端验收**。

国务院搜索JSON接口曾返回200但totalCount=0，未作为已验证历史检索路径。CDP只能补渲染，不保证每家脚本列表都可用；证监会部分栏目、交易所等仍需逐站验证。空计划不自动扩大范围，可改用已核实的具体文章URL或 `policy_import`。

## 7. 测试

```bash
npm run test:policy-official
npm run test:policy
```

包含离线提取测试、文章子页XLSX发现、共享预算、全失败状态、发布日期与统计期区分、串行节流、重定向拒绝行为测试。模拟测试不代替官方站点在线许可和可用性验证。
