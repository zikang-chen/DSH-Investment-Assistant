# 产品复审与改动（2026-11-24）

这一轮按“看图 → 数据可信 → 别丢用户输入 → 资本与组合的操作流”排序处理，先修会误导判断或造成数据丢失的问题，再谈界面的组织方式。

## 一、所有走势图都有分时

新增统一的 `MarketChart`（`src/client/market-chart.tsx`），四个入口共用同一套切换与身份规则：

| 入口 | 原来 | 现在 |
| --- | --- | --- |
| 行情页走势 | 有分时，但按钮依赖本地日K缓存 | 统一：K线 / 分时 / 5日分时 |
| 证券资料页 | 只有日K | 统一，并支持场内 ETF 用成交价而不是净值 |
| AI 解读里的走势 | 只有日K | 统一 |
| 全球指数展开 | 只有日K | 日K + 分时（按 secid 取分钟行情） |

口径：

- 日K 只有交易日（日期），不伪造时分；分时才有分钟时刻。二者不互相补造。
- 场外基金只有净值（T+1），按钮禁用并说明；场内 ETF 走成交价与分时，同时保留净值口径。
- 全球指数/商品的分钟时间保留源侧原文，时区未核准时 `at` 留空、图表按源覆盖范围铺轴，不假设交易时段。

## 二、Agent 也能取分时

新增 `get_intraday_data`：`code`+`kind`（a/hk/us/global）或 `secid`，`days` 1 或 5，返回分钟价格、均价、量额、来源、时区/单位与 warnings，带 `offset/limit` 分页与总数。未知时区不做 +08:00 推断。

## 三、修掉的可复现缺陷

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| 取消请求被当成源故障 | 两次取消即让该数据源对所有标的熔断 60 秒 | 取消直接抛出，不记失败、不入缓存 |
| 切换数据源后旧请求写回缓存 | 之后仍返回已移除的来源 | 策略版本号校验，变更即丢弃在途结果 |
| 全球带点代码被截断 | `106.BRK.B` 的正确响应被拒绝 | 完整比较代码 |
| 日K十字光标错一根 | 读数显示下一交易日 | 修正内边距与实际画布缩放 |
| 空态→有数据不测宽 | 图表长期按 560px 布局导致错位 | 有数据时重挂尺寸监听 |
| 坏日期进入K线后切周崩溃 | `2026-99-99` 触发异常 | 日期真值校验 |
| 分时累计量跨缺口当分钟量 | 少见的缺分钟会把两分钟量记在一分钟 | 只在相邻分钟差分 |
| 新浪备用源拿旧快照当实时 | 加拿大指数一年前价格、伦铜冒用 COMEX 铜 | 按行情时间拦截过期，错误映射撤销 |
| 行情读失败显示成空状态 | 首屏失败像“没有持仓/没有指数” | 明确失败提示与重试，保留旧报价并标时点 |
| 研究资料删除无确认 | 误点永久删除正文与批注 | 明确标题、永久性与未保存改动提示，可改归档 |
| 证据请求切选错绑 | 按 A 说明填的材料可能提交到 B | 详情与提交绑定 id，切选即清空表单 |
| 研究正文跨页静默丢失 | 切页即丢未保存内容 | 离开前确认 |

## 四、我的资本：按账面结构组织

参考 Portfolio Performance 的账户与交易流水组织方式（[getting started](https://www.portfolio-performance.info/en/)）与 Sharesight 的“先账户、再流水、再看收益”路径，页面改为三个入口：**资产与收益 / 账户 / 流水**。

- 顶部只给三件事：加账户、准备流水、刷新；其余按需展开。
- 流水页现在**直接在本页查询**（新增只读 `GET /capital/transactions`，支持账户/类型/日期/标的过滤），不再绕到对话里看结果。
- 账户页按账户列出币种与现金，可直接跳到该账户的流水。
- 新增账户与流水仍是“草稿 → 核对 → 交给 Agent 记账”，不假装页面直接入账。

竞品参考：Portfolio Performance 官方站与文档；Sharesight 帮助中心的账户/交易结构。二者都强调“账本流水是唯一事实来源、报表是派生”，本次沿用了这一点。

## 五、组合策略：按流程收口

参考 Portfolio Visualizer 的组合回测入口（[portfolio backtesting](https://www.portfoliovisualizer.com/backtest-portfolio)）与 Portfolio Performance 的再平衡说明（[rebalancing](https://help.portfolio-performance.info/en/concepts/performance/rebalancing/)），页面按 **当前组合 → 目标与预算 → 检查漂移 → 保存与审批 → 数据核验/回测** 排列：

- 主路径是三张表加两个按钮；“高级（单项专属范围）”“环境变化证据”默认折叠。
- 保存与审批区合并，批准按钮明确“纸面跟踪，不执行交易”；载入历史版本改为编辑副本，不再覆盖当前表单。
- 核验与回测仍是纸面实验；输入需要来源与日期，缺公司行动覆盖声明时只输出部分口径。

## 六、文案

去掉了“候选市场识别”“不按代码位数猜基金”“不自动换算汇率”“空白不按 0”“只生成预览不直接写入”这类解释实现的长句，改为操作名和短提示；保留必要信息：币种与单位、数据时点、预览待确认、失败原因、权限确认。`scripts/test_product_copy.ts` 用 TypeScript AST 只检查可见文案，避免误扫业务 prompt 与注释。
