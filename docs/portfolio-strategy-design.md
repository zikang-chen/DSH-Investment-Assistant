# 综合组合策略：产品重设计

## 为什么重做

此前“策略实验室”以单股票规则回测为中心，不符合多持仓投资策略的工作对象。本轮改为组合政策工作区，单股实验降到高级折叠区，不把多张单股曲线拼成组合策略。

竞品依据见[官方资料调研](<portfolio-competitors.md>)。PV公开产品页可确认多资产、多组合、再平衡周期/偏离带、现金流和基准对照；Composer公开介绍可确认自然语言构建/回测/执行的一体化主张，但本插件不复制实盘执行。第三方品牌/代码/数据许可分别核查，不因公开网页即假定可复制。

## 产品闭环

1. 组合定义：2–20个持仓，股票/基金/债券/黄金等用户标记资产类别，当前权重、战略目标及现金。
2. 风险预算：单资产上限、资产类别上限、最低现金、单次换手预算、偏离触发阈值和复核周期。
3. 环境变化：行情/资金/相关性、国内政策与国际事件以附来源日期的证据输入；变化先触发复核，不直接改变战略基线。
4. 对照预览：当前vs目标集中度、类别/币种暴露、逐项漂移、含现金换手、约束合规与证据缺口。
5. Agent调研：保留原目标方案与战术候选对照，补价格/基金穿透/相关性等证据，记录原因及失效条件。
6. 人工确认：本轮无自动应用、无账本写入/订单。新规则不得覆盖旧草案，来源及版本应由Agent落资料库保留。

## 已实现的边界

- 输入权重0–1，界面用百分比；当前和目标含现金分别合计1，不默默归一化。
- 单资产、类别、现金、换手和可选单资产min/max强约束。
- HHI含现金桶；币种暴露只是已折算权重分组，不直接加总原币金额。
- 证据需真实日期与来源；未来和超过30天排除。来源文本存在不等于真实性已核验。
- 估值日期缺失/过期保留数学对照，但不生成proposed确认方案；executionReady永久false。
- 复核周期到期、权重漂移、风险/支持证据及约束违例产生解释性trigger。
- 浏览器兼容纯函数，稳定非密码学FNV标识用于对照，不作为防篡改签名。
- 已有单标的价格回测保留在高级区，不是组合收益回测。

## 使用

投资判断→组合策略。手工填写资产、类别、币种、当前/目标权重与估值日期，再填写现金及风险预算，点击检查。用户没有授权时不读取持仓。需要在线调研时点Agent按钮，将本次明确输入的草案发到当前会话。

工具portfolio_strategy_review(input JSON)与页面复用同一确定性函数。

## 尚未实现，不能宣称已有

- 多资产历史再平衡回测、交易税费/最小手数/分红的组合账务；
- 自动读取持仓并验证FX，自动基金穿透、协方差/风险贡献计算；
- 战略/战术组合的持久化版本库与可点击审批状态机；
- 新闻自动映射成合理权重、自动调仓或真实执行；
- 无浏览器实测时不能声称表单布局和点击链路全部验收。

这些不能由一个“综合评分”代替。首版目标是把决策对象和约束先纠正，后续按实际数据支持增加组合回测。

## 验证

17组纯组合核心测试：无效权重/日期/重复id、预算约束、币种暴露、现金换手、证据时效、不可变输入、确定性标识及安全标志；构建和原金融回归另行运行。原始个人资料不写入公开仓库。
