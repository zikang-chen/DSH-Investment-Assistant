# 只和 Agent 对话，怎样完成有证据的投研

你可以直接说目标，不必自己操作每一个工具或把资料拼成报告。Agent 应先理解问题，再按需要检索真实资料，给出能追溯、能被推翻、可复核的条件性判断。

这份说明描述现有能力的研究路线与限制，不表示每个数据源当前都在线，也不表示已经完成真实端到端验收。

## 可以这样问

- 「研究腾讯未来一年，结合官方年报、近期新闻、国内国际政策、全球与中国市场、资金和走势。不要读我的账户。」
- 「看看这只基金的经理任期、持仓、历史收益与回撤、费用；重仓公司的营收和现金流是否支持它的逻辑？」
- 「美国通胀、欧洲利率与中国信贷变化，对这个行业有什么传导？给支持与反对证据，不要只看 NBS。」
- 「我有一份白皮书/政策书，帮我导入并分析原文；请区分政策目标和实际落地。」
- 「上次判断新增了什么证据？哪些条件已经失效？」

以上是使用示例，不是任何具体股票/基金的投资建议。

## Agent 应怎样处理

### 1. 先把对象和意图说清

核对名称/代码、市场、股票还是基金、基金份额类别、报价币种、目标和期限。名称片段（如只说一个管理人或指数简称）、同名、多市场对象不唯一时，应展示真实候选让你选，不擅自选第一个。

普通资料研究不需要你的账户。**持仓授权默认关闭**；只有你明确授权本次问题使用个人资产后，Agent 才能读取相关本机持仓/账本或运行会读取它们的模拟、穿透与重叠分析。未授权时报告写「未使用个人持仓」。

### 2. 按问题选择证据，不是所有工具全跑

先找已有资料，确认时效；之后才补缺口。身份确认后，互不依赖的官方财报、新闻、相关政策/宏观、行情/资金可以按需并行，避免重复取数。找到具体链接再读正文；确定基金持仓后再选企业查财报。

只问经理和回撤，不必默认研究全球所有政策。问综合风险时，也不应只抓一条新闻就下结论。

### 3. 股票的年报必须真正读到原文

优先公司投资者关系（IR）、交易所和监管披露原文，核对财年、合并范围、币种、单位、审计/调整口径。新闻、券商研报和财务摘要可以补充视角，但不能冒充官方年报。

拿到 PDF 链接、下载成功或导入成功，都不代表 PDF 已读。必须实际读到并核对正文/页码/表格后，才能说明实际读过哪些部分。只有摘要时，应直说「未核对年报正文」。

你合法提供并授权读取的本地 PDF，可以让 Agent 先加载当前可用的 `office` 技能，用 `office_render` 把所需页渲染为图片，再用 `read_image` 逐页读取并核对页码/表格，整理研究所需摘录。只读相关页不能称读完整份年报/白皮书；`office_convert` 不支持 PDF 转文本。

核对后的摘录可通过 `policy_import(text,...)` 导入政策库，或通过 `save_research` 保存财报/其他资料，明示「人工/视觉转录」、范围/页码与原文件出处；存疑数字待核，不能升级为官方核验。转录文本不改变原始文件哈希，也不是产品后台自动批量 PDF 抽取。

要区分三件事：原文件字节存档、抽取正文、官方核验。目前 `policy_import` 的 PDF 只存原文快照（`pdf-pending`）；`evidence_submit` 的 PDF 也只存字节，并非自动 PDF 解析器。上面的实际读取路径来自 Agent 的文档能力，不是 policy/evidence 自动解析。扫描件无法辨认或关键 PDF 抽取/核对失败时，应创建 **critical Evidence Request**（待补证据请求），说明需要哪一页/哪张表、期间和单位，只做受限分析，不给受阻结论的交易方案。

### 4. 基金和公司分开研究

基金看经理任期、持仓及披露日期、规模、历史收益/回撤/波动、基准、费用和交易规则。单位净值通常 T+1，不是实时成交价；当前本地风险计算使用单位净值，不能冒充含分红再投资的总回报。

研究企业财务时，先确认实际重仓名单/权重，再按重要性核对企业官方财报。要交代前 N 大持仓覆盖范围与披露滞后；不能把公司营业收入合成「基金营业收入」，也不能直接拿来预测基金净值。

`fund_dossier` / `stock_dossier` 的工具回执现在包含各 section 的**有界真实数据预览**（含来源、数据时点、缺失与截断范围），不再是「只有状态/条数」。但预览有上限（数组 6 项、对象 30 字段、文本 1200 字符等），不能当成完整年报、全部持仓或全文已读；超出范围要按 `dataPresentation.followUp` 用单项工具或官方原文补查。经理可从实际基金画像字段/管理人披露取，场外基金重仓需官方定期报告或已发现并核对的其他工具；内部服务存在不等于独立 Agent 工具可用。费用也不能按行业常见值猜填。ETF 另需折溢价与交易规则。

### 5. 全球不只 NBS，但覆盖必须诚实

现有 `get_macro_china` 是由东财提供的中国 CPI、PPI、PMI、GDP、货币供应五类序列，不是通用全球宏观接口。中国证据还可以按问题核对人民银行、财政部、海关等官方原文。

全球公开材料可通过当前会话可用的 `web_search` / `web_fetch` 查找具体官方发布：

| 来源 | 可研究的问题示例 |
| --- | --- |
| [BLS](https://www.bls.gov/) / [BEA](https://www.bea.gov/) | 美国通胀、就业、GDP/PCE |
| [Fed](https://www.federalreserve.gov/) | FOMC 声明、政策利率与纪要 |
| [ECB](https://www.ecb.europa.eu/) / [Eurostat](https://ec.europa.eu/eurostat/) | 欧元区政策、通胀与增长 |
| [IMF](https://www.imf.org/) / [World Bank](https://www.worldbank.org/) / [OECD](https://www.oecd.org/) | 全球与国家比较、实绩与预测 |

这些是官方检索入口，不是保证可直接查询的新 API。**不存在通用全球结构化宏观工具**，也没有保证所有全球指数、外汇、商品实时行情都覆盖。脚本页面、解析失败、数据过期或缺少工具时，报告必须写出缺口。各地区季调/同比环比/年化/预测版本也不能混用。

## 白皮书和政策书怎么导入

- 已允许的官方 URL：先检查 `policy_sources`，再用 `policy_import(url)`；URL 抓取受 allowlist 等实际限制。
- **国际官方来源不一定在 allowlist 内，未允许的 URL 不能宣称可直接入政策库。** 可以合法读取公开网页时，保留链接与允许引用的摘录，用 `save_research` 存资料库；这不是政策库政策 id。
- 你合法取得/获授权提供的本地 PDF/HTML/Markdown/文本文件，或粘贴正文，可以用 `policy_import(filePath/text)`。不绕过登录、验证码、付费或站点限制，不为导入擅改 host 配置。
- PDF 原文保存与正文抽取分开；提取失败走待补证据，不直接生成「已核对原文」结论。补正文后需核对实际 id/版本，不保证自动合并旧 PDF。
- 引用应包含来源、日期、文件类型/效力、版本和实际段落/页码。新版与旧版有真实记录才做对比；目标、预算、拨付、订单和财报兑现分开。

## 数据缺失后如何继续

Agent 应先查已有资料与合法可用来源。缺口会改变结论时，创建可持续的 Evidence Request，告诉你 requestId、问题、缺什么、为什么拿不到、建议官方栏目、期间/单位和恢复后的下一步。

你可以补链接、正文、合法本地文件或手工数值。系统校验后才能恢复：`evidence_submit` → 查看 `validation/issues` → 必要时由你确认解析内容 → `ACCEPTED` → `evidence_research_resume`。用户提供或人工确认不等于官方核验；国际官方链接也不保证被现有国内域名识别规则自动判成官方。

暂时找不到可以明确跳过，但报告仍保留缺口。证据不足（`INSUFFICIENT_DATA`）是正式结果，不附行动方案、价格区间或仓位指令。

## 应得到什么结果

1. 简明的条件性结论，或者明确的证据不足。
2. 研究范围、期限、数据时点，以及是否使用个人持仓。
3. 可定位的官方原文/数据和新闻/研报观点，注明来源、日期、期间、币种/单位及实际核对范围。
4. 支持证据、反对证据、判断失效条件；事实与条件推断分开。
5. 缺口、待补请求、复核日期与触发事件；价格区间如有必须能复算。
6. 资料库路径与保存成功的 adviceId。只有真实成功回执才说「已保存」；可以在资料 tab 继续维护，在后续对话追加复核，而不抹掉原判断。

缺价格不按零、也不用成本假装现价；缺汇率时按币种分列，不造统一总资产或仓位。组合模拟不会执行交易，不会自动修改账本。需要真实收益时，还要区分持仓快照与资金交易流水，追加本金不是盈利。

## 验证范围

本次增加的是研究技能、参考手册、用户说明与静态契约测试，不是新的全球数据 API、PDF 解析引擎或自动交易功能。

静态检查仅证明路由内容和现有源码合同存在，不证明网站在线、PDF 可读、数字正确或真实端到端已经通过。后续真实验收应分别核对：同名消歧、官方年报原文、基金经理/持仓企业财报、全球官方材料、国际 URL allowlist 拒绝、PDF 解析失败、未授权持仓不读取、缺价/汇率降级、双链保存和到期复核。

开发者可运行 `node --import tsx scripts/test_research_playbook.ts`。该脚本只读文档/源码，不发网络请求、不运行金融工具、不读写个人数据；其成功输出会明确标注「仅静态契约，非真实端到端」。
