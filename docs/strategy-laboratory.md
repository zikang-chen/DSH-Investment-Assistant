# 策略实验室：价格实验与市场环境复核

版本：首版1.0，2026-11-17。入口：投资判断→组合策略→高级单标的规则实验。主工作区已重做为[多持仓组合政策](<portfolio-strategy-design.md>)；本页仅说明高级单标的实验，不是整体组合模型。仍为DSH插件，无真实交易接口。

## 已实现

1. 输入普通A股主板代码与CNY模拟本金，点击运行；服务端独立取得最多最近1200根未复权日线，不读取真实持仓、不覆盖图表历史缓存。
2. 严格门禁：支持600/601/603/605/000/001/002前缀、当前名称非ST/退市风险、币种CNY、至少180根、有效日期且严格递增、正价OHLC关系、成交量已知非负、来源与带时区抓取时间。
3. 固定三个模板：买入持有近似（momentum 1/-100）、MA20/60、20日动量0阈值。非基准择优，不自动搜索参数。
4. 全段、前70%描述段、后30%独立现金重置的留出段；历史仅因果预热，测试首日收盘信号最早次日开盘执行。
5. 示例成本：100股整手、T+1、3bps佣金/最低5元、5bps卖出税、5bps滑点、10%涨跌停近似；双倍成本敏感性。不是个人券商实际费率。
6. 返回数据/规则/配置hash、来源URL/抓取时间/范围、收益/回撤/换手/费用与权益轨迹，结果可以重新计算。

## 为什么只用未复权行情

图表hfq/qfq价格不等于当时成交价，不能直接用来计算100股整手与最低佣金。本实验拒绝调整口径与unknown，不从已缓存hfq序列拼凑执行价格。

未复权也有局限：分红/送转/拆股可能产生非经济跳变；没有完整公司行动账务。因此这是**价格规则实验，不是含股息总回报回测**，不宣称可成交收益或策略有效。

## 随行情、市场和国际形势调整

页面“让Agent复核市场环境”只投递任务，不假装已完成调研。Agent按问题取得：

- 行情趋势、波动、资金、市场宽度；
- 全球指数、美元/利率/商品等快照；
- 官方央行、贸易、监管与国际事件原文；
- 国内政策及公司基本面实际兑现证据。

每条填写topic、claim、source、asOf、direction（risk/support/neutral），调用strategy_environment_review：

- 超过30天、未来、非法日期或缺字段的证据拒绝；
- 至少有有效支持与风险证据，否则保留缺口；
- 返回REVIEW_ONLY、autoChange=false，不选股、不直接生成订单；
- 来源填写不等于来源已核验，Agent仍需读取真实资料；
- 当前事件不能回填历史信号，避免前视偏差。

如需调整：写明旧版本hash、规则变化、依据和反证，用已有submit_strategy保存新proposed草案，再验证并等待用户批准。冻结规则不静默改写，不自动激活。可复用研究由Agent保存资料库；单次页面实验目前只在本页显示，不自动沉淀数据库或生成定时任务。

## 工具和路由

- strategy_experiment(code, initialCash)：取数、门禁、固定模板价格实验。
- strategy_environment_review(signals, asOf)：纯证据时效/完整性复核。
- 原submit_strategy/get_strategy_library：草案保存和读取，不重复注册。
- POST /strategy/experiment：与Agent工具复用同一服务。

## 限制

历史ST/上市早期交易限制未按日重建，10%规则仅普通主板近似；当前名称校验不能证明历史从未ST。单标的无幸存者偏差修正或多资产FX，停牌/涨跌停仅保守日频近似。留出结果也不是统计显著性证明。初始版本暂未将动量与波动率组合为新DSL，避免未经测试扩展规则。

## 验证

npm run build：插件与客户端构建。未做真实浏览器视觉验收；在线接口在当次环境可失败，会显示拒绝/错误而非演示收益。
