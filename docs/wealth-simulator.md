# 复利与财富模拟器（Wealth Simulator）

> 目标：把「每月投 X、年化 Y、N 年后有多少」变成确定性计算，而不是让模型口算。
>
> 所有公式在 `src/wealth/compound.ts`，整数分，纯函数，可单测。

## 1. 公式与口径（必须写清楚）

| 场景 | 公式 | 说明 |
| --- | --- | --- |
| 一次性本金 | `FV = PV × (1+r)^n` | r 是**年有效收益率** |
| 期末定投 | `FV = PV(1+r)^n + PMT × ((1+r)^n − 1)/r` | r=0 时取极限 `PV + PMT×n` |
| 期初定投 | `FV = PV(1+r)^n + PMT × ((1+r)^n − 1)/r × (1+r)` | 期初比期末多一期 |
| 年→期利率 | `period = (1+annual)^(1/n) − 1` | **不是** `annual/n` |
| 实际收益率 | `real = (1+nominal)/(1+inflation) − 1` | **不是** `nominal − inflation` |
| 费后收益 | `net = (1+r)(1−fee) − 1` | 费率按年化 |
| 不规则现金流 | `FV = Σ CF_i × (1+r)^(days_i/365)` | act/365，晚于估值日的跳过 |

面板/工具里的参数写 `0.08` 或 `8` 都可（大于 1 时按百分数处理）。

## 2. 两种模式

**确定性情景**（已实现）：本金、月/季/年定投、期限、年有效收益率、年费、通胀、定投年增幅 → 逐年明细（投入、收益、名义、实际购买力）。

**历史分布 / 蒙特卡洛**（未实现）：需要样本区间、权重、再平衡规则、随机种子等；本轮不做，避免用历史样本冒充未来分布。

## 3. 目标反解

`wealth_goal_solve` 用二分法反解：

- `contribution`：给定期限/收益率，求每期需投多少；
- `years`：给定投入/收益率，求需要多少年；
- `rate`：给定投入/期限，求需要多少年化收益率。

条件不可达时返回 `null` 并说明（例如零收益、零投入、目标大于 0），**不给「大概」数值**。

## 4. 方案保存

`data/wealth/plans.json`：保存输入 + 当时的确定性结果快照 + `engineVersion`。
重新计算用 `wealth_plan_compare(recompute=true)`，会报告快照与当前引擎的差异。

情景名（稳健/基准/压力）**只是标签**，不代表任何收益概率。

## 5. 工具

| 工具 | 作用 |
| --- | --- |
| `compound_calculate` | 复利计算（逐年明细 + 假设） |
| `wealth_cashflow_calculate` | 不规则日期现金流终值 |
| `wealth_goal_solve` | 目标反解（投入/年限/收益率） |
| `wealth_plan_create` | 保存情景 |
| `wealth_plan_compare` | 对比情景（可重算） |

## 6. 纪律

- 不预测收益：所有输出都带「确定性情景，不是收益预测」。
- 不默认「每年都能拿到同一个收益率」：文案必须说明波动与结构变化。
- 费用与税费是用户假设，不冒充个人税务建议。
- 结果只用于规划，不修改任何真实持仓或账户。

## 7. 测试

```bash
npm run test:wealth    # 19 项离线
```

−10% 两年 = 8100；费后 8.9% 两年 ≈ 11892.1；两笔 1000（一笔一年前、一笔当期）@10% = 2100。
