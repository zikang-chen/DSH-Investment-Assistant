# 使用可靠性审查（2026-11-17）

## 本轮已修复

- 历史增量在 qfq/hfq 冲突时禁止以几天数据替换多年缓存；保留原历史并明确要求全量迁移。
- 相同口径的局部/短窗口响应改为合并，避免源站降级时截断历史。
- 不同口径迁移仅允许在无分页错误、无截断、覆盖原起止范围的完整请求后执行。
- 分页后续请求失败保留 error/truncatedAt；检测源站忽略 end 的重复页。
- K线刷新不再因最后一根标今天而永久停止；可见页面每90秒检查更新，且按标的避免重复在途请求。
- 切换标的/输入代码会失效旧请求；同步异常显示真实错误而不是静默吞掉。
- “已是最新交易日”改成“含当日K线（可能未收盘，非实时成交）”；疑似间隔不再声称已确认缺交易日。
- 腾讯适配器只接收所请求复权字段，避免把 day/qfqday 错标成 hfqday。
- 官方采集扫描文章详情页附件；失败/重复也占 maxDocs 预算；失败不能返回整体成功。
- 政策筛选使用可靠完整发布日期，不拿标题中的统计月份冒充发布日期。
- 官方抓取默认串行节流；HTTP 重定向在每次发送前检查允许清单，避免先访问越界主机后拒绝。

## 测试证据

- `npm run build` 通过（tsc + 客户端 bundle）。
- 28 个独立契约/行为测试脚本通过，含 history-sync、policy-official-runtime、policy-redirect。
- 金融回归：regressions 19、quant 28、policy 46、evidence 13、capital 21、wealth 19、investment 23、learn 14 通过。
- 本轮测试只使用模拟数据与临时目录；未重写用户持仓或本地历史缓存。

## 未作成功保证的边界

1. 90秒为检查/请求节奏，不是逐笔实时。实际新鲜度还受上游延迟及 Provider 缓存TTL（可能300秒）限制。
2. 全球行情仍为独立 /global/kline 路径（最多500根），并非自动取得所有国家上市以来历史，也没有逐笔推送。
3. 后复权值不等于可成交现价；未验证 Provider 的复权口径仍需标 unknown，不能混入确定口径回测。
4. 疑似间隔只按工作日估算，未接完整交易所节假日/停牌日历；“无长间隔”不等于完整性已核验。
5. 动态JS列表、登录/验证码、附件结构化解析仍有覆盖限制；本轮没有验证所有官方网站在线可用。
6. 尚未连接真实浏览器进行视觉与交互验收，不以静态契约代替浏览器验收。
