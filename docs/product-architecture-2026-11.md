# 竞品对照与产品重构（2026-11-24）

这一轮不是照抄功能，而是先看清几类成熟产品各自解决什么问题，再决定本项目该补哪一块。

## 一、参考对象与它们的真实形态

### dsh-trading（同生态，最近的参照）

公开仓库 [zhu1090093659/dsh-trading](https://github.com/zhu1090093659/dsh-trading) 把自己定义为「基于 DSH 与 Cordis 的 Agent 原生全市场交易终端」，README 里可核实的要点：

- **23 个连接器**（加密/美股/A股/港股/期货/全球），连接器是独立 npm 包，按市场装；
- **三视图中栏工作台**：行情 / 策略回测与选股 / 知识库（力导知识图谱）；
- **右栏常驻驾驶舱**：定时任务、统一持仓台账、快讯、宏观日历与利率、文件、预测市场；
- **统一自选与持仓账本**（`@dshtrading/watchlist`、`@dshtrading/holdings`），跨品种同一份；
- **Agent 是终端的一等公民**：行情、盘口、下单都是工具面，`trading_batch` 批处理；
- **执行闸门**：下单默认 dry-run，实盘要显式开关 + 人工审批 + Ed25519 授权，无头环境 fail-closed；
- **文档即事实页**：[docs/current-state.md](https://github.com/zhu1090093659/dsh-trading/blob/main/docs/current-state.md) 只写现在时事实、可复现命令与硬停项。

它做的事比本项目重得多（真实下单、交易所凭证、桌面端打包），**本项目不复制执行面**：我们没有券商通道，也不该假装有。

### 交易看盘类：TradingView / Koyfin

- TradingView：以「图表 + 自选 + 告警」为核心，图表是全产品的主对象，指标、画线、多周期共用同一套交互（[lightweight-charts](https://tradingview.github.io/lightweight-charts/) 是它的开源图表库）。
- Koyfin：同一标的下把「价格 / 财务 / 估值 / 对比」做成可切换的视图，强调快速横向比较。

对本项目的启发：**标的是第一类对象**，图表与资料应该围绕它切换，而不是每个页面各存一份代码输入框。

### 账户与绩效类：Portfolio Performance / Sharesight

- [Portfolio Performance](https://www.portfolio-performance.info/en/)：账户 → 交易流水 → 报表，流水是唯一事实来源，报告全部派生；再平衡按「当前 / 目标 / 偏离」展示。
- Sharesight：先建账户与持仓，再自动算已实现/未实现、分红与费用，强调「一笔交易进出都留痕」。

启发：**账本与报表分离**；查询流水是账本自身的功能，不该让用户去对话里问。

### 组合与回测类：Portfolio Visualizer

[Portfolio Visualizer](https://www.portfoliovisualizer.com/backtest-portfolio) 的主路径是：选资产与权重 → 设定区间与再平衡 → 看组合表现与对照。参数有默认值，先出结果再调细节。

启发：**先给可运行的主路径，再暴露高级项**；不要把 JSON 当第一入口。

| --- | --- | --- | --- | --- |
| 核心对象 | 标的 + 连接器 + Agent | 标的 + 图表 | 账户 + 流水 | 标的 + 组合 + 账本 |

| 安全边界 | fail-closed 不变量成文 | — | — | 不猜身份、不补 0、不谎报来源 |

## 三、本轮落地的改动

1. **标的上下文条**（`src/client/instrument-focus.tsx`）：从行情、证券档案、外部命令选中一只标的后，面板记住它；顶部一条显示名称/价格/时点，并提供 K线 / 分时 / 档案 / 问 Agent 四个动作，切页不丢。持久化失败或存量脏数据都会安全降级。
2. **图表统一**（上一轮已完成并在本轮沿用）：四个入口同一套 K线与分时切换，日 K 只有交易日、分时才有分钟时刻。
3. **资本页任务化**：资产与收益 / 账户 / 流水三段，流水在本页按条件查询。
4. **组合策略流程化**：当前 → 目标与预算 → 漂移检查 → 保存与审批；高级项默认折叠。
5. **Agent 取分钟数据**：`get_intraday_data`，带来源、时区与分页。

## 四、明确不做的

- **真实下单与券商凭证**：没有合规通道，也不该在个人工具里假装能做。
- **跨市场连接器矩阵**：dsh-trading 的 23 个连接器是它的核心资产，本项目保持「公开免费源 + 本地 CLI」的轻量路线。
- **多智能体角色编排**：现阶段先保证单 Agent 的工具面可靠，角色拆分留到有明确收益时再做。
