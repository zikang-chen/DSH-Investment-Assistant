# K 线与事件：历史覆盖、复权口径与更新机制

更新：2026-11-17。本文描述当前工作区实现；构建成功不等于运行中的宿主已重新加载。

## 1. 两条数据路径

| 入口 | 数据路径 | 覆盖与限制 |
|---|---|---|
| A/H/美股本地 K 线与事件 | `/history`、`/history/sync`、本地 HistoryStore | 支持历史缓存、增量同步、事件标记 |
| 全球行情、指数内嵌 K 线 | `/global/kline`，真实 secid | 当前最多500根；不保证上市以来全量，不自动具备个股事件 |
| 基金 | 单位净值历史 | `none`口径，净值通常T+1，非盘中成交价 |

共用 KlineChart 提供日/周/月聚合、MA、缩放平移、十字光标与「全部」按钮；「全部」只表示已取得的数据，不表示源站完整历史。快捷键 A 全览、R 复位，Home/End 跳到首末窗口。

## 2. 历史请求与完整性

A股历史请求显式从1990-01-01开始；港美股使用4000自然日窗口。分页最多5页，不同上游的历史范围、分页上限及日期支持不同。后续分页失败或源站忽略截止日期时停止并报告，不据此声称完整。

此前本机实测：601988后复权4935根（2006-07-05至2026-11-17）、601868后复权1243根。它们是特定时点样例，不保证其他标的有相同覆盖。

## 3. 复权口径与缓存保护

历史同步向支持的源请求hfq（后复权）。前复权对长期分红股可能产生零/负的早期调整价格，旧正价校验曾丢弃这类数据。后复权也依赖上游实现，**不宣称任何源都恒正或等同总回报指数**。

- 后复权价格不是当日可成交价；不能直接当买卖点位。
- 腾讯只读取请求对应的hfqday/qfqday/day，缺少对应字段则失败，不把其他字段错标口径。
- 未确认的Provider口径标unknown，不能据此声称适合正式回测。
- 同口径数据采用合并；源站只返回短窗口不再截断多年缓存。
- 增量请求遇到口径冲突：保留原历史、返回明确错误，要求完整同步。
- 口径迁移须全量响应覆盖旧起止范围，且没有已报告分页错误/截断，才允许整体替换；事件保留。

## 4. 更新不等于逐笔实时

可见K线页面每90秒检查增量同步；最后一根即使标今天也可更新，避免盘中蜡烛停在旧值。重叠窗口从最后一根前5天开始；同标的在途请求去重，页面隐藏时不主动刷新。

**90秒是前端检查节奏，不是数据新鲜度保证。** Provider缓存TTL、行情源延迟、交易所时区/休市与网络均会影响结果。页面标「含当日K线（可能未收盘，非实时成交）」，不能据日期就宣称实时。

本地路径的刷新机制不等同全球K线、基金净值或分时逐笔行情。全球路径当前为打开时取数，未实现统一逐笔推送。

## 4.1 分时（当日 / 近 5 日）

K 线工作区顶部有 `日K / 分时 / 5日分时` 三个模式，同一标的切换不需要重新同步历史：

| 模式 | 数据 | 来源 |
| --- | --- | --- |
| 日K | 本地历史库（复权口径见第 3 节） | 同步时写入 |
| 分时 | 当日分钟价格 + 均价 + 分钟量 | 东财 `trends2`（`push2his`），失败回落腾讯分钟接口 |
| 5日分时 | 近 5 个交易日的分钟价格 | 仅东财 `trends2` |

口径与限制：

- 分时**不除权**，只适合当日/近 5 日看盘，不能拿来做长期收益或回测。
- 腾讯备用源只有当日数据：请求 5 日、或请求美股分时，会明确报错「需要东财可用」，不会返回残缺曲线。
- 均价线：东财直接给均价；腾讯只给累计成交额与累计成交量，本项目按 `累计额 ÷ (累计量 × 100)`（A 股 1 手=100 股）计算当日 VWAP。
- 基金没有分时成交价（净值 T+1），面板直接说明，不发请求。
- 时间保留源侧原文（交易所当地时间），另存 ISO 便于排序；两条不一致时以原文为准。

## 5. 缺口与事件

疑似长间隔以≥15个工作日估算，按大小排序、最多10条。未接完整交易所节假日/停牌日历，因此：

- 不能把工作日数写成确定缺失交易日；
- 没有长间隔不代表完整性已核验；
- 不通过补0或虚构bar填空。

周/月聚合事件映射到所在周期。财报报告期与公告可得日不同，缺公告日必须标注，不能把报告期当时点回测中的已知信息。

## 6. 操作与排障

1. 更新后执行`npm run build`；宿主服务端需要重载插件/重启宿主，浏览器刷新不保证重载服务端。
2. 查看页面显示的代码、市场身份、起止日期、根数及错误。
3. 旧qfq缓存遇到hfq增量冲突时点「同步」完整拉取，不手工混合两套口径。
4. 若源站只返回最近区间，保留缓存并报告覆盖边界，不声称已恢复上市以来全部历史。

## 7. 验证

`npm run test:history-sync`、`npm run test:kline-math`、`npm run test:history`。

离线测试覆盖增量冲突不丢历史、局部响应不截断缓存、同日可刷新、分页边界、聚合/事件/视窗。真实浏览器视觉与上游实时性仍须另行验收。
